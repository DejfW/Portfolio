Semantic HTML5 Landmark Tree

How assistive technologies parse the Orkiestra document outline

  • <nav aria-label="Skip links"> (navigation landmark)

    Provides immediate keyboard bypass blocks to #main-content, #sidebar-nav, and search.

  • <header class="app-header"> (banner landmark)

    Houses brand link, <form role="search"> landmark, role="toolbar" quick actions, and aria-haspopup="menu" account button.

  • <nav aria-label="Breadcrumb"> (navigation landmark)

    Ordered list (<ol>) of hierarchical links with aria-current="page" on the active location.

  • <aside aria-labelledby="..."> (complementary landmark)

    Pairs workspace context with <nav aria-label="Workspace sections"> supporting roving arrow keys.

  • <main id="main-content" tabindex="-1"> (main landmark)

    Primary content target with named <section aria-labelledby="..."> regions, <dl> key-value stats, <table> with <caption>, and <details> disclosures.

  • <footer class="app-footer"> (contentinfo landmark)

    Document-level metadata and secondary accessibility navigation links.
